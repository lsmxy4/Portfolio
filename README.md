# 신동환 개발자 포트폴리오

백엔드 개발자 취업을 위한 개인 포트폴리오입니다. 프로젝트 경험과 기술 스택, 각 프로젝트의 제작 구조를 소개합니다.

## 최근 업데이트 · 2026년 11월 7일

- 네이비·시안 다크 테마와 라이트 모드, Header·Footer 및 Home 리뉴얼
- 프로젝트 12개 등록과 데이터 파일 분리, GitHub·배포 링크 정리
- FitMap·SmartRAD·Fresh Chain을 대형 프로젝트로 소개
- 전체 프로젝트 상세 페이지에 소개·주요 기능·제작 방식·기술 스택 추가
- 프로젝트 주제를 표현한 파스텔 3D 썸네일 적용
- Skills를 실제 프로젝트 사용 기술과 근거 링크 중심으로 개편하고 그래프 애니메이션 추가
- 모바일 레이아웃, 키보드 포커스, 모션 감소 설정 및 기본 SEO 개선
- Vercel에서 상세 페이지 새로고침을 지원하는 SPA rewrite 설정 추가

## 기술 스택

React · JavaScript(JSX) · Vite · SCSS · React Router · Framer Motion

포트폴리오 소스는 JavaScript·JSX를 유지합니다. 프로젝트 소개에 나오는 TypeScript는 해당 프로젝트의 사용 기술입니다.

## 실행

```sh
npm install
npm run dev
```

```sh
npm run lint
npm run build
npm run preview
```

빌드 결과물은 `dist/`에 생성됩니다. 현재 ESLint·빌드 및 전체 프로젝트 상세 페이지의 렌더링·링크 점검을 통과했습니다. 브라우저 시각 검증과 외부 배포 사이트의 실제 동작은 별도 확인이 필요합니다.

## 작업 및 배포

- 작업 브랜치: `redesign`
- 병합 대상: `main` (Pull Request로 검토 후 병합 예정)
- 배포 대상: Vercel (`main`을 Production Branch로 설정 예정)
- 이번 작업에서 커밋·푸시·배포는 수행하지 않았습니다.

프로젝트 설명은 저장소에서 확인한 내용을 기준으로 작성했습니다. 확인되지 않은 개발 기간·담당 역할·성과는 추가하지 않았으며, 공개 주소가 없는 프로젝트는 사이트 준비 중으로 안내합니다.
